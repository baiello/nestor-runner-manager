# Nestor Runner Manager

Turns a Mac into a machine of [Nestor](https://nestor.kocoa.fr): it runs the tasks of your agents, with the tools of your Mac.

This repository publishes its releases only. The app updates itself from them.

## Install

1. Download `NestorRunnerManager-X.Y.Z.zip` from the [latest release](https://github.com/baiello/nestor-runner-manager/releases/latest).
2. Unzip it and move **Nestor Runner Manager** to Applications.
3. Open it, install its service, then choose **Link to Nestor…** and enter the code it shows on Nestor's Machines page.

Requires macOS 15 or later.
